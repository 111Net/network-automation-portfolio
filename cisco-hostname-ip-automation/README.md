# Cisco Hostname & IP Automation

Python automation script for configuring Cisco IOS hostnames and interface IP addresses using Netmiko.

## Features
- Configure hostname
- Configure interface IP
- Enable interfaces
- Save configurations

## Technologies
- Python
- Netmiko
- Cisco IOS

## Installation

```bash
pip install netmiko
```

## Usage

```bash
python3 hostname_ip.py
```
